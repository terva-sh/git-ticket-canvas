Proposed defaults

Title first. Fixed status/priority row, then textual warnings, up to two labels with a keyboard-operable +N disclosure, ownership, AC count and secondary ID/type. Done and archived titles use ordinary readable text. No progress bar for tickets without criteria.

Selected relationships by default. No selection means no edges. Solid arrows point to dependencies; dashed arrows point from parent to child. All and None do not move cards.

Inspector starts at 400 px and resizes between 320 and 560 px. This preview uses a keyboard-accessible width slider; implementation would also add a drag separator. On narrow screens, the inspector moves below the horizontally scrollable canvas in this proposal.

Interactive preview controls: theme, relationship mode, label disclosure, inspector width and section disclosures. Card gestures and ticket editing are deliberately not implemented. Example D intentionally has no acceptance criteria to demonstrate the absent progress bar.
